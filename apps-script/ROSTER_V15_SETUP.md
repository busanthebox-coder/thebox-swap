# THEBOX v15 · 스터디 고정 요일 실시간 연결
현재 GitHub Pages 경로 /leader/ 와 /native/는 **읽기 전용 실험 화면**이다. 기존 사이트 /thebox-swap/ 는 건드리지 않는다.

## 연결 범위
- GitHub Pages frontend: 기존 Apps Script API `weeks`, `topics`, `swaps` 호출. 앱은 **읽기 전용**.
- 원어민: 리더 17명 목록만. 학생 이름 데이터가 페이지 코드에 없음.
- 리더: `secureRoster`를 설치하고 개인 비밀 코드를 발급해야 본인의 월수 / 화목 / 주말 A·B 멤버 이름, 고정요일을 **시트에서 직접** 가져올 수 있음.
- 변경된 고정 요일은 Google Sheets `월수`, `화목`, `주말` 시트의 고정요일 열이 정본이며, 프런트에서는 저장하지 않음.
- 현재 스냅샷(2026-10-18): 월수 A10/B7, 화목 A10/B9, 주말 A8/B7. 이하경=목일, 김보령=목토. 김재혁 공란.

## Apps Script 안전한 적용 방법 (대표/소유자만)
1. 현재 Apps Script 프로젝트를 **백업**.
2. GitHub `apps-script/Code.gs`의 `handle` switch에 새로 추가한 `case 'secureRoster'`를 현재 운영본의 동일한 위치에 추가한다. **기존 코드를 일괄 덮어쓰지 않는다**.
3. 새로운 Apps Script 파일 `secure-roster-v15.gs`를 만들고 [이 코드](./secure-roster-v15.gs) 전체를 붙여넣는다.
4. Apps Script에서 `setupOneRosterCodeV15()`를 관리자 수동 실행하고 로그에 출력되는 코드를 **해당 리더에게만** 비공개로 전달한다. 다른 리더는 해당 함수 안의 이름을 수정한 뒤 별도로 실행한다. 코드는 스크립트 속성에 SHA-256 해시만 저장된다.
5. 배포 → 배포 관리 → 기존 웹 앱 편집 → **새 버전** 배포. URL을 바꾸지 않는다.
6. /leader/ 페이지에서 코드를 입력하여 본인 A/B만 나오는지 확인한다. /native/ 페이지에는 학생 명단을 표시할 수 없다.

## 주의
- 이 GitHub 코드 변경만으로 현재 운영 중인 Apps Script 배포는 자동 갱신되지 않는다.
- 코드 미발급/배포 전에는 `secureRoster`가 응답하지 않는다. 기존 대타와 주제는 계속 사용한다.
- 개인 코드 발급 시 실제 운영 인원의 책임자를 확인한다. 코드가 유출되면 회전 재발급한다.
- 인증 없는 이름 선택으로 보이는 정규 리더 명단은 시연용이다. **로그인 완료를 의미하지 않는다**.
- 기존 Apps Script 쓰기 액션(addSwap 등)은 현재 공개되어 있으므로, 운영 도입 전 변경 요청에 대한 인증 정책도 별도 점검해야 한다.
