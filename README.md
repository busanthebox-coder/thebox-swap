# 더박스 대타 보드

매장 화이트보드에 적던 대타를 그대로 옮긴 웹앱입니다.
못 나오는 사람이 날짜에 이름을 올리면, 대신 갈 사람이 "대타 갈게요"를 눌러 확정합니다.

**주소** — https://busanthebox-coder.github.io/thebox-swap/

## 어떻게 쓰나요

1. 처음 열면 **이름만** 입력합니다. 계정도 비밀번호도 없습니다.
2. 못 나오는 날이 생기면 `+ 대타 요청` — 날짜, (선택) 시간·사유·할 일을 적습니다.
3. 달력에서 **붉은 날 = 아직 대타를 못 구한 날**. 확정되면 표시가 사라집니다.
4. 다른 사람 요청을 열어 `대타 갈게요`를 누르면 **그 자리에서 확정**됩니다. 관리자 승인은 없습니다.
5. `내 기록` 탭에서 내가 몇 번 구했고 몇 번 나갔는지 볼 수 있습니다.

근무표를 미리 등록하지 않습니다. 스케줄 변동이 잦아서, "이 날 못 나옴" 한 건씩만 올리는 방식입니다.

## 구조

```
index.html              앱 화면
assets/app.js           전체 로직 (프레임워크 없음)
assets/style.css        스타일
config.js               Supabase 주소·키  ← 여기만 채우면 공유 모드
supabase/schema.sql     테이블 + RLS 정책
```

빌드 도구가 없습니다. 파일을 고쳐서 `main`에 푸시하면 GitHub Pages가 그대로 배포합니다.

## 로컬 모드 vs 공유 모드

`config.js`가 비어 있으면 **로컬 모드** — 데이터가 브라우저에만 저장되고 다른 사람에게는 보이지 않습니다.
화면 위에 안내 띠가 뜹니다.

**공유 모드로 바꾸려면**

1. [supabase.com](https://supabase.com) 무료 가입 → `New project`
2. 대시보드 → `SQL Editor` → `supabase/schema.sql` 내용을 붙여넣고 Run
3. `Project Settings → Data API` 에서 **Project URL** 과 **anon public key** 복사
4. `config.js` 두 줄에 붙여넣고 커밋

`anon key`는 브라우저에 노출되는 게 정상인 공개 키입니다. 실제 제어는 `schema.sql`의 RLS 정책이 합니다.

## 알아둘 것

- **동시 클릭**은 서버에서 걸러집니다. 두 사람이 같은 요청에 "대타 갈게요"를 눌러도 먼저 닿은 쪽만 확정되고, 나머지에게는 "방금 다른 분이 먼저 확정했어요"가 뜹니다.
- **본인 확인이 없습니다.** 이름만으로 들어오므로 남의 이름을 고를 수도 있습니다. 스태프끼리 쓰는 신뢰 기반 보드로 설계했습니다. 서버가 본인 확인까지 하게 하려면 Supabase Auth를 붙여야 합니다.
- 다른 사람이 올리거나 확정한 내용은 **20초마다** 자동으로 반영됩니다.
- 휴대폰에서 `홈 화면에 추가`하면 앱처럼 열립니다.
