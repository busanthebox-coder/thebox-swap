# 더박스 대타 보드

매장 화이트보드에 적던 대타를 그대로 옮긴 웹앱입니다.
못 나오는 사람이 날짜에 이름을 올리면, 대신 갈 사람이 "대타 갈게요"를 눌러 확정합니다.

**주소** — https://busanthebox-coder.github.io/thebox-swap/

## 어떻게 쓰나요

1. 처음 열면 **이름만** 입력합니다. 계정도 비밀번호도 없습니다.
2. 못 나오는 날이 생기면 `+ 대타 요청` — 날짜, 그리고 필요하면 시간·사유·**대타 하는 원어민 변경 사항**(이름/교재 & 청소 유무)을 적습니다.
3. 달력에서 **붉은 날 = 아직 대타를 못 구한 날**. 확정되면 표시가 사라집니다.
4. 다른 사람 요청을 열어 `대타 갈게요`를 누르면 **그 자리에서 확정**됩니다. 관리자 승인은 없습니다.
5. `내 기록` 탭에서 내가 몇 번 구했고 몇 번 나갔는지 볼 수 있습니다.

근무표를 미리 등록하지 않습니다. 스케줄 변동이 잦아서, "이 날 못 나옴" 한 건씩만 올리는 방식입니다.

## 구조

```
index.html              앱 화면
assets/app.js           전체 로직 (프레임워크 없음)
assets/style.css        스타일
config.js               구글 시트 주소  ← 여기만 채우면 공유 모드
apps-script/Code.gs     구글 시트 백엔드
```

빌드 도구가 없습니다. 파일을 고쳐 `main`에 푸시하면 GitHub Pages가 그대로 배포합니다.

## 구글 시트 붙이기 (한 번만)

`config.js`가 비어 있으면 **로컬 모드** — 데이터가 각자 브라우저에만 저장되고 서로에게 보이지 않습니다.
화면 위에 주황 안내 띠가 뜹니다. 스태프끼리 공유하려면:

1. 쓸 구글 시트를 엽니다. 데이터는 **`대타` 탭**에, 이름 목록은 **`스태프` 탭**에 쌓입니다. (탭 이름은 `Code.gs` 맨 위에서 바꿀 수 있습니다)
2. 시트 상단 **확장 프로그램 → Apps Script**
3. 편집기에 있던 내용을 지우고, [`apps-script/Code.gs`](apps-script/Code.gs) 를 **전부** 붙여넣고 저장(⌘S)
4. 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(톱니바퀴) → **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ← 이게 핵심입니다. 스태프가 구글 로그인 없이 쓰게 됩니다
   - **배포** → 권한 승인 (처음 한 번, "안전하지 않음" 경고가 떠도 본인 스크립트이므로 계속 진행)
5. 나온 **웹 앱 URL**(`.../exec` 로 끝남)을 `config.js` 의 `GAS_URL` 에 붙여넣고 커밋

`대타` / `스태프` 탭과 헤더는 첫 사용 때 자동으로 만들어집니다.
이미 다른 내용이 들어 있는 탭이면 **덮어쓰지 않고 에러를 냅니다** — 기존 데이터를 지우지 않기 위해서입니다.
그럴 땐 탭을 비우거나 `Code.gs` 의 `SHEET_SWAP` 을 다른 탭 이름으로 바꾸세요.

> **코드를 고친 뒤에는** 반드시 `배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포` 를 해야 반영됩니다.
> 새 배포를 만들면 URL이 바뀌므로, 기존 배포를 수정하는 쪽이 편합니다.

## 알아둘 것

- **동시 클릭**은 서버에서 걸러집니다. 두 사람이 같은 요청에 "대타 갈게요"를 눌러도 먼저 닿은 쪽만 확정되고, 나머지에게는 "방금 ○○ 님이 먼저 확정했어요"가 뜹니다. (Apps Script `LockService`)
- **본인 확인이 없습니다.** 이름만으로 들어오므로 남의 이름을 고를 수도 있습니다. 스태프끼리 쓰는 신뢰 기반 보드로 설계했습니다.
- **웹 앱 URL을 아는 사람은 글을 쓸 수 있습니다.** 비밀번호가 아니라 주소일 뿐이니 계정이 털리지는 않지만, 스태프끼리만 공유하세요.
- 다른 사람이 올리거나 확정한 내용은 **60초마다**, 그리고 앱으로 돌아올 때마다 자동 반영됩니다.
- 취소한 요청도 시트에는 `canceled` 로 남습니다. 기록이 사라지지 않습니다.
- **웹 앱 URL이 이 공개 레포의 `config.js` 에 들어갑니다.** 레포를 보는 사람은 누구나 그 주소를 알 수 있습니다.
- 휴대폰에서 `홈 화면에 추가`하면 앱처럼 열립니다.
